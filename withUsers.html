About Prompt Engineering Assistant

The Prompt Engineering Assistant is designed to help users create effective prompts for Large Language Models (LLMs) by following best practices and guidelines.

Our Mission

We aim to democratize access to high-quality prompt engineering by providing:

  • Step-by-step guidance for creating prompts
  • Direct access to prompt engineering best practices
  • AI-powered prompt improvement suggestions
  • A growing library of example prompts

The Guidelines

Our prompt engineering guidelines are based on the comprehensive work:

Prompt Engineering Guide

Author: Lee Boonstra

Download PDF

Key Principles

The guide emphasizes several key principles for effective prompt engineering:

Specificity

Prompts should be clear and specific about the desired output, including any constraints or requirements.

Context

Providing relevant context helps the model understand the task and generate more accurate responses.

Examples

Including examples (few-shot learning) can significantly improve the model's performance.

Structure

Well-structured prompts with clear instructions lead to more consistent results.
